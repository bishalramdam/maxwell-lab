# Maxwell Lab

Interactive, animated lab benches for Maxwell's four equations of electromagnetism. Plain HTML, CSS and JavaScript, no build step.

**Live site:** https://bishalramdam.github.io/maxwell-lab/

| Page | Law | Experiment |
|---|---|---|
| `index.html` | Overview | The four equations in differential and integral form |
| `1-gauss-electric.html` | Gauss's law | Drag charges; a Gaussian surface measures flux = Q_enc/ε₀ |
| `2-gauss-magnetic.html` | Gauss's law for magnetism | Bar magnets, iron filings, cut a magnet in half: net flux is always zero |
| `3-faraday.html` | Faraday's law | Magnet through a coil with galvanometer, plus an AC generator |
| `4-ampere-maxwell.html` | Ampère–Maxwell law | Compasses around wires, Ampèrian loop, charging capacitor and displacement current |
| `5-light.html` | All four together | 3D electromagnetic wave across the spectrum; c = 1/√(μ₀ε₀) |

Open `index.html` in any modern browser to run it locally.
